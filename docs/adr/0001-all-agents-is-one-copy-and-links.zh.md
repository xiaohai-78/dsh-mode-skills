# 「所有 Agent」是一份文件加链接，不是复制

使用范围为「所有 Agent」的 Skill 只保留一份，放在共享目录里，DSH 和直接读这个目录的工具原样使用。电脑上装的其他 Agent 工具，在自己的 Skill 目录里得到一个指向这一份的链接（Windows 上是目录联接，不需要管理员权限）。复制的话，只要有一个工具里的副本被改过，各份就不一样了；而且这正是 `npx skills add -g` 的目录结构，两边装的能互相认出。

## 后果

- 其他工具里同名但文件不同的 Skill 不会被替换；内容相同的副本会换成链接，原来那份放进回收站。
- 改成「仅 DSH」或删除 Skill 时，只删除指向这个 Skill 的链接；其他工具目录里的文件夹和文件一律不删。
